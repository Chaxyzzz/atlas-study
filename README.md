## Installation

Clone repository

```bash
git clone https://github.com/Chaxyzzz/atlas-study.git
```

Install dependencies

```bash
composer install
```

Create environment file

```bash
cp .env.example .env
```

Generate application key

```bash
php artisan key:generate
```

Run database migration

```bash
php artisan migrate
```

Start development server

```bash
php artisan serve
```
